# Python Learning — Hands-On Practice

Runnable, teach-by-example files. Each has: explanation → working example →
exercises → solutions at the bottom. Run any with `python3 <file>.py`.

| File | Covers |
|------|--------|
| `python_functions_practice.py` | All function types: built-ins, def, args/kwargs, lambda, map/filter/reduce, closures, decorators, generators, recursion, type hints (+ 10 practice programs) |
| `python_builtins_reference.py` | ~70 built-in functions grouped by purpose, with examples |
| `python_data_structures_practice.py` | Lists, tuples, sets, dicts, comprehensions, `collections` |
| `python_oop_practice.py` | Classes, `__init__`, `@property`, inheritance, polymorphism, dunder methods, class/static methods, dataclasses |

Suggested order: functions → builtins → data structures → OOP.
